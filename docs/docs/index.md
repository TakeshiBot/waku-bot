# Giới thiệu

**waku** là bot Telegram đa chức năng, phát triển bằng
[Pyrogram/Kurigram](https://github.com/KurimuzonAkuma/pyrogram), có AI agent và
bảng quản trị Mini App. Repository và phân phối Python mang tên `waku-bot`.
Source được phát hành theo giấy phép GNU AGPL v3.

Tiếng Việt (`vi`) là ngôn ngữ mặc định và ngôn ngữ dự phòng. Múi giờ mặc định
là `Asia/Ho_Chi_Minh` (UTC+7).

- [Triển khai bot](self-host.md)
- [Cấu hình bảng quản trị](webapp.md)
- [Quốc tế hóa và tiếng Việt](i18n.md)
- [Đổi tên dự án và múi giờ](branding-timezone.md)
- [Giấy phép](license.md)

Namespace Python `kmua` được giữ để bảo toàn import và entrypoint; lệnh chạy
source vẫn là `python -m kmua`.
