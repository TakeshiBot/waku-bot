# Quốc tế hóa và tiếng Việt

## Phạm vi triển khai

Tiếng Việt (`vi`) là ngôn ngữ mặc định và ngôn ngữ dự phòng của bot và Mini App.
`vi-VN` và `vi_VN` được chuẩn hóa về `vi`. Tiếng Trung, tiếng Anh và các ngôn ngữ
khác đã có trong bot vẫn được giữ lại. Lựa chọn ngôn ngữ đã lưu của từng người dùng
hoặc nhóm không bị ghi đè; bản ghi mới hoặc chưa có trường `lang` dùng tiếng Việt.
Đổi ngôn ngữ của tài khoản hoặc nhóm cũ bằng `/lang` hoặc bảng quản trị. Thay đổi
`lang` trong `settings.toml` không tự đổi ngôn ngữ của những bản ghi này.

## Kế hoạch và phân công

1. Kiểm kê catalogue hiện có và các chuỗi hardcode bằng AST Python, tìm kiếm Unicode
   và rà soát Vue/TypeScript; phân loại nội dung hiển thị, prompt, dữ liệu và giao thức.
2. Nhóm Mini App: bổ sung catalogue tiếng Việt, đưa nhãn/placeholder/nội dung trạng thái
   vào i18n, cập nhật lựa chọn ngôn ngữ và định dạng số/ngày.
3. Nhóm backend: bot Telegram, nút Inline, quà tặng, xác minh, thông báo API và caption.
4. Nhóm AI: prompt mặc định, ngữ cảnh hội thoại, lời nhắc media, phản hồi tools;
   truyền ngôn ngữ theo từng tác vụ để không lẫn ngôn ngữ giữa các cuộc trò chuyện.
5. Tích hợp: đổi mặc định ở cấu hình, model database, i18n và script dev; dịch toàn bộ
   catalogue có sẵn; bổ sung các key thiếu phát hiện trong quá trình kiểm tra.
6. Kiểm tra độ phủ key, loại dữ liệu, placeholder, câu hỏi/đáp án xác minh,
   fallback và bảo toàn lựa chọn ngôn ngữ. Chạy test backend độc lập, frontend test,
   typecheck, lint và build; rà soát diff và các chuỗi tiếng Trung còn lại.

## Quy tắc bảo toàn hành vi

- Giữ nguyên tên lệnh, callback data, enum, trường JSON, ID, URL, tên file và cú pháp
  máy đọc. Giữ các tên riêng hoặc tên ngôn ngữ bản địa trong danh sách ngôn ngữ.
- Nội dung người dùng, prompt tùy chỉnh, RSS hoặc dữ liệu lấy từ bên ngoài không
  được tự dịch. Chỉ dịch phần lời dẫn do ứng dụng tạo.
- Giữ placeholder, HTML/Markdown và công thức toán. Khi dịch câu hỏi xác minh,
  dịch đồng bộ các lựa chọn và đáp án để đáp án vẫn nằm trong danh sách lựa chọn.
- Các alias tiếng Trung mà parser meme nhận diện và tài nguyên meme có chữ sẵn
  được giữ để tương thích. Nhãn/hướng dẫn do ứng dụng tạo phải qua i18n.
- Comment, docstring kỹ thuật và log chẩn đoán không phải giao diện người dùng.
  Thông báo log đã có key i18n được bổ sung bản Việt; không dịch tên giao thức
  hoặc lỗi nguyên gốc của thư viện bên ngoài.
- Mẫu câu đùa trong trạng thái tải có thể được điều chỉnh về cách nói tự nhiên
  trong tiếng Việt. Nội dung chứa từ lóng nhạy cảm dùng cách nói nhẹ hơn.

## Cấu trúc catalogue

Backend: `waku/i18n/locales/vi/` chứa bộ dịch gốc (`bot.yml`), nội dung được trích
từ bot/API (`bot.hardcoded.yml`), AI (`bot.agent.yml`) và prompt cấu hình
(`bot.prompts.yml`). Các file được nạp theo thứ tự ổn định. Lỗi cú pháp catalogue
được báo ngay thay vì bị bỏ qua âm thầm.

Frontend: `webapp/src/i18n/vi.json`, cùng cấu trúc key và placeholder với
`en.json` và `zh-CN.json`.

Thêm key mới phải bổ sung đủ tiếng Việt, tiếng Anh và tiếng Trung. Không ghép các
mảnh câu nếu có thể dùng một mẫu với placeholder. Bộ dịch tiếng Việt phải bao phủ
mọi key của bộ gốc; không được dùng tiếng Trung làm fallback mặc định.

## Kiểm tra trước khi phát hành

```powershell
python -m pytest tests -q
python scripts/check_i18n.py
cd webapp
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

Test catalogue và các test dùng stub có thể chạy độc lập. Chạy thử bot thật cần
Python 3.13, toàn bộ dependencies của `pyproject.toml`, cấu hình hợp lệ và môi
trường Telegram. Agent shell dùng Landlock/landrun nên cần Linux; Docker là một
cách triển khai theo cấu hình có sẵn của dự án.

## Kết quả kiểm chứng lần triển khai này

- Catalogue Việt: **1.058 key backend**, **456 key frontend**.
- Backend: **59 test đạt**, gồm fallback/alias, mặc định cấu hình, bảo toàn ngôn ngữ
  đã lưu, cấu trúc và placeholder, cô lập locale giữa tác vụ, tiếp tục hội thoại nhóm,
  giao thức RSS, câu hỏi xác minh, parser meme, nguyên nhân lỗi API, múi giờ UTC+7,
  lịch chạy, log và chuyển đổi thời gian Telegram.
- Frontend: **115 test đạt** trong 14 file dưới môi trường `TZ=UTC`; typecheck,
  lint và production build đạt. Test mới kiểm tra ngày giờ UTC+7, biên ngày của
  bộ lọc, offset được chỉ định và giá trị ngày giờ không hợp lệ.
- Ruff trên các file Python thay đổi đạt; audit source và `git diff --check` đạt.
  Kiểm tra dependency lock bằng `uv lock --check --offline` đạt.
- Audit AST không còn chuỗi runtime tiếng Trung chưa phân loại; các chuỗi được giữ
  là alias tương thích/parser và tên tài nguyên ảnh. Comment/docstring kỹ thuật
  tiếng Trung đã được chuyển sang tiếng Anh. Kiểm tra thêm
  nội dung tiếng Anh hardcode tại các lời gọi gửi/trả lời tin nhắn.
- Thêm CI `.github/workflows/i18n.yml` dùng Python 3.13 và dependency lock của dự án
  để chạy bộ test cùng script audit khi source/catalogue thay đổi.

Kiểm tra backend tại máy này chạy bằng Python 3.13.16 với các dependency kiểm thử
trong môi trường cô lập; một số luồng AI được kiểm tra bằng mock/stub. Chưa chạy
`uv sync --frozen` với toàn bộ dependency runtime trên Windows vì `uvloop` cần
Linux. Chưa chạy build/runtime Docker, bot Telegram thật, API mô hình thật hoặc
GitHub CI trong phiên này; chưa triển khai dịch vụ.
